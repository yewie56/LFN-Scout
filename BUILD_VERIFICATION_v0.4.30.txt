Java-17-Logik:
- vorhandenes JDK17 im aktuellen Projekt bevorzugt
- Suche in anderen AndroidStudioProjects
- Suche in .jdks und .gradle/jdks
- Suche in Android-Studio-JBR, aber nur wenn tatsächlich Java 17
- Suche in üblichen JDK-Installationspfaden
- JAVA_HOME nur verwenden, wenn es Java 17 ist
- Download von Temurin 17 ausschließlich als letzte Möglichkeit
- Downloadanzeige mit 40-Zeichen-Balken, Prozent und MB
- gefundener Pfad wird in .tools/java17.path gespeichert
- gradle.properties wird projektlokal auf das gefundene JDK gesetzt
- globales Java 8 wird nicht verändert
