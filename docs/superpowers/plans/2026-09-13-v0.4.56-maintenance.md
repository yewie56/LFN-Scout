# LFN-Scout v0.4.56 Maintenance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement persistent developer-configurable comment timeouts, visible log saving, developer-only location precision, local-clock waterfall time labels, and non-destructive continuous Rolling Buffer behavior.

**Architecture:** Keep existing DataStore and Compose architecture. Store four timeout values in `ReminderSettingsStore`; UI exposes them only in developer mode but all modes consume them. Waterfall rendering receives an absolute start time and formats five local `HH:mm:ss` labels. Rolling snapshot save remains a lock-protected copy and must not call stop/restart/reset.

**Tech Stack:** Kotlin, Jetpack Compose, Preferences DataStore, Android MediaStore, existing self-test tools.

**Spec:** Conversation requirements through 2026-09-13.

## Global Constraints
- Version becomes 0.4.56.
- Timeout defaults: rating 5s/5s; audio 60s/10s.
- Timeout settings visible/editable only in developer mode, but always used in normal mode too.
- Location accuracy meters visible only in developer mode and hidden in normal exported logs.
- Waterfall time labels use local `HH:mm:ss`; 30-minute rolling uses five labels.
- Rolling Buffer save must not stop, restart, clear, or reset the running stream or ring position.
- Supabase backend files remain unchanged.
